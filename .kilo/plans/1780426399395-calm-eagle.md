# Plano: Melhorias Tipográficas + Pipeline Hero

## 1. Instalar Cabinet Grotesk via @fontsource

```bash
pnpm add @fontsource/cabinet-grotesk
```

## 2. Atualizar `app/layout.tsx`

Substituir fontes:
- **Remover**: Outfit, DM Serif Display, JetBrains Mono
- **Adicionar**: 
  - `Instrument Serif` (Google Fonts) como `--font-heading` — usar só o peso `400` (italic é o charme dela)
  - `Cabinet Grotesk` (via `@fontsource/cabinet-grotesk`) como `--font-sans` — importar com `import "@fontsource/cabinet-grotesk/400.css"` e `import "@fontsource/cabinet-grotesk/500.css"` e `import "@fontsource/cabinet-grotesk/700.css"`
  - Manter JetBrains Mono como `--font-mono`

Estrutura do layout:
```tsx
import "@fontsource/cabinet-grotesk/400.css";
import "@fontsource/cabinet-grotesk/500.css";
import "@fontsource/cabinet-grotesk/700.css";
import { Instrument_Serif, JetBrains_Mono } from "next/font/google";

const instrumentSerif = Instrument_Serif({
  weight: ["400"],
  subsets: ["latin"],
  variable: "--font-heading",
  display: "swap",
});

const jetbrainsMono = JetBrains_Mono({
  subsets: ["latin"],
  variable: "--font-mono",
  display: "swap",
});

// html class: `${instrumentSerif.variable} ${jetbrainsMono.variable}`
```

## 3. Atualizar `app/css/style.css` — Tema

No bloco `@theme`, atualizar:
```css
--font-sans: "Cabinet Grotesk", sans-serif;
--font-heading: "Instrument Serif", serif;
--font-mono: "JetBrains Mono", monospace;
```

## 4. Reescrever `components/hero.tsx` — Pipeline Visual Melhorado

### Problemas atuais:
- Pipeline steps apenas highlight sequencial sem mostrar "fluxo"
- Barra de progresso genérica desconectada dos steps
- Sem "partícula" viajando entre os steps
- Texto de status sem impacto visual

### Novo design do pipeline:

**Estrutura visual**: 3 steps conectados por uma linha horizontal. Uma "data packet" (partícula brilhante) viaja ao longo da linha, como se fosse uma mensagem sendo processada.

**Animações**:
1. **Partícula viajante**: Um círculo com glow azul que se move horizontalmente entre os steps usando `translateX` com transição suave
2. **Step atual**: Borda animada com gradiente girando (concentric spin), ícone pulsa suavemente
3. **Step completado**: Ícone vira checkmark verde com animação de escala, fundo verde claro
4. **Step futuro**: Opaco, escala 0.9
5. **Log de status**: "Terminal" com typing animation — letras aparecem uma a uma simulando um log real
6. **Linha de conexão**: Gradiente animado que "flui" da esquerda pra direita

**Pipeline visual** (substituir bloco right side do hero):

- Barra de progresso total sutil

### Detalhes da animação do pipeline:

1. Estado inicial (t=0): step WhatsApp ativo, packet na posição 0%
2. Após 2.5s: step Pagamento ativo, packet move para 50%
3. Após 5s: step Boleto ativo, packet move para 100%
4. Após 7.5s: volta para step WhatsApp (loop)
5. Em cada step, o log exibe as 4 linhas uma a uma com typing animation (500ms entre cada linha)

**Typing animation**: Usar `useState` com `visibleLines` que incrementa a cada 500ms no useEffect quando o step muda, e um `useState` para o texto atual com efeito de digitação caractere por caractere (opcional, pode ser só revelar linha a linha para simplificar).
